# IconeEspecialidade

Ícones vetoriais das 13 especialidades, em traço simples de 2px sobre grade de 24, legíveis de 24px a 48px.

## Origem
Oito vêm do Lucide (licença ISC): cardiologia (heart-pulse), clínico geral (stethoscope), neurologia (brain), ortopedia (bone), imunologia (virus), pediatria (baby), oftalmologia (eye), otorrinolaringologia (ear). Cinco são desenho próprio no mesmo traço, porque o Lucide não tem: gastroenterologia (estômago), ginecologia (útero), dermatologia (corte da pele), obstetrícia (perfil de gestante) e pneumologia (pulmões).

## Uso
- No app, dentro do círculo `teal50` de 88px, em 48px e cor `primaria`.
- Os SVG avulsos ficam no grupo de assets Especialidades, já com tinta `primaria` (#015F68).
- Substituem as ilustrações 3D de órgãos da prototipação, pesadas demais para o pacote do app.
