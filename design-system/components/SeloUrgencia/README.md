# SeloUrgencia

Selo do nível de urgência da pré-triagem em 3 níveis: rotina, prioritário e emergência.

| nivel | Texto | Ícone | Estilo |
|---|---|---|---|
| rotina | Rotina | circle-dot | contorno `primaria` |
| prioritario | Prioritário | chevrons-up | preenchido `atencao` |
| emergencia | Emergência | triangle-alert | preenchido `erro` |

## Regras
- O leitor de tela ouve "Urgência: Prioritário".
- Emergência no selo nunca aparece sozinha: a tela também mostra o `BannerEmergencia`.
