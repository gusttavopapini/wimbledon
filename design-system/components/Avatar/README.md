# Avatar

Foto redonda ou iniciais em `primaria` com `textoSobrePrimaria`; aparece ao lado do nome escrito.

## O que você fornece
`nome` (gera as iniciais, ignorando "Dr."/"Dra."), `foto` opcional, `tamanho` (48, 64 ou 96; padrão 64) e `descricao` só quando o avatar estiver sozinho, sem o nome ao lado.

## Regras
- Ao lado do nome, o avatar é decorativo (sem texto alternativo) para o leitor de tela não repetir o nome.
- Sobre o `Topo`, ganha um anel branco de 3px.
