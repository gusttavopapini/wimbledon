# CartaoProfissional

Cartão-botão com avatar, nome, especialidade e unidade de um profissional; o cartão inteiro é o alvo de toque.

## O que você fornece
`nome` (com "Dr." ou "Dra."), `especialidade`, `unidade`, `foto` opcional (sem foto mostra as iniciais), `detalhe` opcional ("Próximo horário: amanhã, às 8h") e `aoTocar`.

## Fora do escopo
Avaliação por estrelas não existe neste produto. Não acrescente nota, ranking nem número de avaliações.

## Regras
- O leitor de tela lê o cartão inteiro como um botão: nome, especialidade e unidade, nessa ordem.
- Lista de profissionais: um embaixo do outro, 12px entre cartões.
