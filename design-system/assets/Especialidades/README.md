# Especialidades

13 ícones de especialidade em SVG, grade 24×24, traço de 2px com pontas arredondadas, tinta `primaria` (#015F68) já aplicada — o `<img>` não herda cor. Para outra cor (alto contraste: #FFD54F), troque o atributo `stroke` ou use o componente `IconeEspecialidade`, que segue a cor do texto.

- Do Lucide (licença ISC, © Lucide Icons and Contributors): cardiologia, clinicoGeral, neurologia, ortopedia, imunologia, pediatria, oftalmologia, otorrinolaringologia.
- Desenho próprio no mesmo traço: gastroenterologia, ginecologia, dermatologia, obstetricia, pneumologia.

Use em 48px dentro do círculo `teal50` de 88px, ou em 24px dentro de chips. Sempre com o nome escrito ao lado.
