# Saúde na Palma da Mão — protótipo navegável

Protótipo de aplicativo de saúde pensado para pessoas idosas: agendamento de consultas, pré-triagem, exames, receitas e opções de acessibilidade (letra maior, alto contraste, leitura em voz alta e Libras).

**Abrir no navegador:** use o link do GitHub Pages deste repositório.

**Rodar no computador:** com o Node.js instalado, dê dois cliques em `iniciar-prototipo.bat` (Windows) ou rode `node servidor.js` e abra http://localhost:8080/.

Todos os dados (pacientes, médicos, clínicas, preços e exames) são fictícios e servem só para demonstração.
